你是「无界问答」项目的验收测试员。这是一个运行在本地的前后端分离 Web 应用：

- 前端：http://127.0.0.1:5173 （React + Vite 开发服务器，已启动）
- 后端：http://localhost:8787 （已启动）
- 项目代码：`D:\无界问答`（client/src 前端源码，server/src 后端源码）

## 应用是什么

导入 PDF 论文后，在**无限画布**上：划选论文文字（或讲解卡片里的文字）→ 浮动工具条「✦ 讲解」→ 划选处着色高亮标注 + 一条虚线连到新的流式讲解卡片；讲解里的文字可继续划选生成下一层讲解（颜色按层级区分：朱砂→青瓷→霁蓝→藤紫→缃黄）。卡片可拖拽（仅标题栏）、加宽（右缘）、独立缩放（Ctrl+滚轮或＋－）、追问（底部输入框）、菜单（⋯：定位标注/重新讲解/删除）。画布可平移（拖空白/空格/滚轮）缩放（Ctrl+滚轮/右下按钮）。

**当前为演示模式**（未配置模型 API Key）：讲解内容是占位模板——这不是缺陷。你要验收的是**功能是否正常、交互逻辑是否正确、UI 是否正确无缺损**，不评价讲解文字的学术质量。

## 工作流程（务必遵守）

1. 先读 `D:\无界问答\验收状态.md`（状态与已知坑）和最新一轮 `验收报告-*.md`（若有）。
2. 用浏览器实测。**必须先通过 Skill 工具加载 `browser-use:control-browser` 技能**获得浏览器驱动方法，再按其 bootstrap 模式驱动浏览器。
3. 每轮覆盖下述清单全部项目；视觉判断用**画布像素级测量**代替看图：对 PDF 标注贴合度，用页面内 JS 读取 pdf-canvas 的 ImageData，扫描标注矩形 x 范围内的深色像素得到字形墨迹的上下沿，与标注矩形的间隙换算成字高百分比（间隙应为正值且 ≤15% 字高）。截图仅作留档（tab.screenshot 存文件），不要依赖肉眼。
4. 把详细报告写入 `D:\无界问答\验收报告-第N轮.md`（N 为轮次，从 1 开始；若文件已存在则覆盖），并在最终回复里给出精简结论。

## 测试清单

**功能与交互（每项给出 通过/失败/无法测 + 证据）**
1. 空状态页：标题/CTA/拖放提示/最近文档列表渲染与点击
2. 打开文档：PDF 页面渲染（两页均出现清晰内容）、页码、文档标题栏
3. PDF 划词→工具条出现（含字数）→ 点「✦ 讲解」→ 标注色块出现 + 虚线连接 + 卡片流式生成 → 完成后标题变为摘要
4. 讲解卡片内划词 → 行内高亮 + 第二层卡片 + 第二条连线（不同颜色）
5. 追问：输入回车 → 问答区追加并流式回答
6. 卡片拖拽（标题栏）：位移准确、连线实时跟随、松手后保持
7. 卡片加宽（右缘拖拽）；卡片独立缩放（＋/－ 与 Ctrl+滚轮）
8. 卡片菜单三项：定位标注（视口补间到标注）/ 重新讲解（内容重流）/ 删除卡片与标注（卡片+标注+连线消失，且讲解之讲解的下游卡片不误删）
9. 画布平移与缩放、右下角「⤢ 论文」回到文档
10. 刷新页面 → 空状态 → 从最近文档恢复：卡片/标注/连线/追问/卡片字号全部恢复
11. 文档菜单：列表/导入入口/删除（可新建第二个文档验证切换，删完回到空状态）
12. 设置弹窗（打开/保存/关闭）、帮助弹窗、Toast 提示、引导提示条
13. 边界：无划选时工具条不出现；Esc 关闭弹窗；空格平移不误选文字

**视觉（截图 + analyze_image 判断）**
- 空状态页、工作区全景（论文+至少 2 张卡片+连线）、划词工具条特写、流式中卡片、设置/帮助弹窗、卡片菜单
- 检查：配色协调（宣纸暖白/墨色/朱砂）、字体正常（衬线正文、无豆腐块）、卡片/标注/连线无错位破损、无文字溢出遮挡、按钮可辨识、暗边/阴影正常

## 纪律

- **只测不改**：不得修改任何项目源码；报告文件与截图除外
- 失败项必须有可复现步骤与证据（截图 URL / DOM 状态 JSON），不许凭空猜
- 无法测的项标注「无法测 + 原因」，不要当成通过
- 已知环境坑（见 验收状态.md）造成的现象不算缺陷，但要在报告里注明
