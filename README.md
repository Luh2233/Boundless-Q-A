# 无界问答 ⧉

**把论文摊开在一张无限画布上 —— 划词即得讲解，讲解还能再讲解。**

导入 PDF 论文后，在任何文字上划选（论文原文、或 AI 讲解里的任何一句），即可生成一张讲解卡片：
划选处自动留下高亮标注，一条虚线把标注和讲解卡片连起来；讲解里的词句同样可以继续划选，
知识就这样一层层向右生长成一棵"讲解树"。所有内容摊在一张可无限平移缩放的画布上，没有滚动条。

## 核心概念

| 概念 | 说明 |
|---|---|
| **无限画布** | 拖拽空白平移、Ctrl+滚轮缩放，画布无边界；论文与全部讲解卡片都是画布上的节点 |
| **划词讲解** | 划选论文或讲解中的文字 → 浮动工具条 → 生成流式讲解卡片 |
| **标注** | 划选处自动着色高亮（PDF 上是半透明色块，讲解内是行内高亮），按层级配色 |
| **关联线** | 标注 → 讲解卡片的贝塞尔虚线，悬停互相高亮；卡片拖动时连线实时跟随 |
| **讲解的讲解** | 讲解卡片内划词生成下一层讲解，颜色区分层级（朱砂→青瓷→霁蓝→藤紫→缃黄） |
| **讲解智能体** | 不是裸调 AI：每次讲解都携带论文全文 + 全部已有讲解的记忆索引 + 祖先讲解链 |
| **记忆** | 每次讲解结束，智能体自动产出摘要/关键概念/关联卡片编号，注入后续所有请求 |
| **追问** | 每张卡片底部可继续提问，带着论文与卡片上下文作答 |

## 快速开始

```bash
# 1. 安装依赖（根目录 / server / client 三处已由 setup 一并处理）
npm run setup

# 2. 开发模式（同时启动后端 8787 与前端 5173）
npm run dev

# 3. 生产模式（构建前端后由后端统一服务）
npm run build
npm start          # → http://127.0.0.1:8787
```

开发模式打开 `http://127.0.0.1:5173`，导入一份 PDF 即可开始。Vite 会把接口和 ChatGPT 登录回调转发到 `8787` 后端。使用 `npm start` 时只需打开 `8787`，它同时提供页面和接口。

**配置模型**：右上角「⚙ 设置」填入任意 **OpenAI 兼容**接口——
智谱 GLM（默认 `https://open.bigmodel.cn/api/paas/v4` + `glm-4.6`）、DeepSeek、OpenAI、Moonshot、本地 Ollama 均可。
不配置 API Key 时以**演示模式**运行（全流程可用，讲解为占位内容）。

如果在自己的电脑上运行，可在「设置 → 连接方式」选择 **ChatGPT 订阅**，用自己的 ChatGPT 账号登录并授权使用订阅额度。选择可用的模型和推理强度，测试连接后保存。该方式无需 API Key，适用于符合 OpenAI 资格要求的账号，生成请求计入账号的订阅额度。知识库收藏后可手动提炼单卡或整个分支。 [OpenAI 开源接入指南](https://developers.openai.com/siwc/token-sharing-open-source)

> 仓库根目录的 `test-paper.pdf` 是一份用于体验的迷你论文，可直接导入试玩。

## 使用速查

| 操作 | 方式 |
|---|---|
| 生成讲解 | 划选文字，松开鼠标后在弹出的输入框提问 |
| 平移画布 | 拖拽空白处 / 空格按住拖任意处 / 滚轮 |
| 缩放画布 | Ctrl（⌘/Alt）+ 滚轮；右下角按钮 |
| 调整卡片文字大小 | 卡片上 Ctrl+滚轮，或标题栏「⋯」菜单中的「缩小文字」「放大文字」 |
| 移动卡片 | 拖拽卡片**标题栏**（正文留给划词，不会误拖） |
| 调整卡片尺寸 | 拖拽任意一边调整单个方向，拖拽任意一角同时调整宽高 |
| 调整 PDF 窗口 | 拖上沿或下沿中央的短横线调整高度，拖右下角或点击「＋」「−」等比缩放 |
| 追问 | 卡片底部输入框回车 |
| 定位原文标注 | 划词生成的卡片标题栏「⋯」菜单 |
| 关闭卡片及其派生卡片 | 卡片标题栏「×」 |
| 回到 PDF | 右下角「定位论文」 |
| 收藏与复习 | 在讲解完成后，从卡片「⋯」菜单选择「加入知识库」。在知识库编辑复习问题和要点，按需展开完整讲解 |

知识库收藏保存在当前浏览器。收藏包含独立的讲解快照，删除原对话或 PDF 后仍可复习。

## 架构与项目规划

```
无界问答/
├── server/                    # Node + Express（无构建步骤）
│   └── src/
│       ├── index.js           # REST + SSE 接口；生产模式托管 client/dist
│       ├── agent.js           # 智能体：提示词、上下文组装、记忆解析、演示模式
│       ├── llm.js             # OpenAI 兼容流式对话客户端
│       └── store.js           # 文件持久化（配置/文档全文/画布状态/PDF 原件）
├── client/                    # React 19 + Vite + TypeScript
│   └── src/
│       ├── store.ts           # 全局状态（zustand）：画布/卡片/标注/讲解流程
│       ├── canvas/            # 无限画布：平移缩放、点阵背景、关联线 SVG 层
│       ├── pdf/               # pdf.js 渲染：懒加载位图 + 自建文本层(划词) + 标注覆盖层
│       ├── cards/             # 讲解卡片：流式 Markdown(+KaTeX)、拖拽、独立缩放、追问
│       ├── marks/             # 划词 → 标注：DOM 包裹、按文本重定位（刷新恢复）
│       └── ui/                # 顶栏/设置/空状态/帮助/工具条
└── scripts/gen-test-paper.mjs # 无依赖生成测试论文 PDF
```

**智能体上下文组装**（server/src/agent.js）——每次讲解请求都包含：

1. 论文全文（超长时：选段所在页 ±1 页全文 + 首尾页 + 其余页开头摘要）；
2. 画布记忆索引：全部已完成卡片的「编号 / 层级 / 摘要 / 关键概念」；
3. 祖先链：选段所在卡片及其上层卡片的**完整讲解内容**（讲解的讲解必备）；
4. 选段原文 + 前后文 ±400 字 + 用户追加问题。

讲解以 `---MEMO---` 分隔符在流末尾附带一段 JSON（摘要/概念/关联卡片），服务端在流式转发时
对分隔符做 hold-back 处理，用户全程只见讲解正文；记忆元数据入库并注入后续所有请求，
`related` 中的关联卡片在卡片底部渲染为可点击跳转的胶囊。

**画布与标注的实现要点**：

- 画布 = `translate + scale` 的世界容器；连线以**世界坐标**绘制在 SVG 层，缩放天然无损，
  仅在卡片/标注移动时重算（rAF 合帧）；
- PDF 标注按选区 client rects 归一化到页面尺寸，存为百分比矩形，任何缩放下都精确；
- 卡片正文渲染完成后 DOM 保持稳定（Markdown 分块 memo），行内标注因此不会丢；
  刷新后按标注文本重新定位（忽略空白差异的文本搜索 + Range 包裹）；
- 拖拽只绑定在标题栏上，正文永远留给文字选择，从机制上杜绝"有时拖不动"。

**设计语言**：宣纸暖白底 + 墨色文字 + 朱砂点缀，讲解正文用衬线字体（Noto Serif SC），
层级用传统色（朱砂/青瓷/霁蓝/藤紫/缃黄）编码卡片顶条、标注与连线。
